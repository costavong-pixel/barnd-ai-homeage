What Pro adds

AI help without handing your provider key to WordPress.

AI remediation drafts

Generate reviewable drafts for metadata, image ALT text, FAQs and internal-link improvements through the Barnd API.

Connected reports

Use server-authorized report workflows while keeping consent, entitlement, usage and site identity tied to the correct installation.

Private updates

Receive Pro releases through a controlled updater path with package/manifest validation and site entitlement checks.

Per-installation security

Each Pro installation receives a unique Ed25519 signing identity. Requests are signed, timestamped and replay-protected.

Tenant isolation

Site A cannot use its credentials to read or act on Site B resources. Cross-tenant, clone, replay and tamper tests are expected to fail closed.

Central cost controls

Provider usage is routed through the Barnd API so model selection, rate limits and cost limits can remain server-controlled.

How Pro calls AI

Your WordPress site never needs our DeepSeek key.

The WordPress plugin signs a request to Barnd AI SEO API. The API authenticates the installation, checks capability and tenant ownership, enforces replay/rate/cost controls, and only then calls the configured AI provider.

What we do not promise

SEO software can improve process, not guarantee rankings.

Barnd AI SEO helps you find issues, structure SEO work and produce reviewable suggestions. Search engines and AI answer systems make their own decisions, so we do not guarantee indexing, rankings, traffic, citations or inclusion in generated answers.
