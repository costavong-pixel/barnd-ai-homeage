FAQ

Questions about Barnd AI SEO

What Free does, what Pro adds, what leaves WordPress, and what the product does not promise.

Do I need Pro to use Barnd AI SEO?

No. SEO Free includes local tools for metadata, canonical/noindex controls, schema, sitemap/LLMs.txt, SEO audits, image ALT review, local SEO, redirects/404s, internal links, Google Performance import and a local AI Discoverability snapshot.

What does SEO Pro add?

Pro adds protected server workflows such as AI-assisted remediation drafts, connected report capabilities, private Pro updates and server-authoritative site entitlements. Pro installations use a hardened signed-authentication model.

Does my WordPress site need a DeepSeek API key?

No. The AI provider credential stays on the Barnd AI SEO API server. The WordPress installation authenticates to Barnd using its own site identity; it does not receive our upstream provider key.

What AI model is used?

The controlled rollout currently routes supported Pro AI actions through DeepSeek Flash V4. Provider routing is server-controlled so the implementation can change without distributing provider credentials to WordPress sites.

Does Barnd AI SEO automatically publish AI changes?

Not by default. Analysis, drafting, mutation and publishing are separate capabilities. Customer defaults are review-first; consequential automation requires separate server-authoritative authorization.

Can a copied plugin or cloned database become another licensed site?

It should not. Hardened Pro uses a unique installation/site binding and per-installation signing identity. Controlled copy/clone tests were expected to fail without an authorized rebind/reactivation.

What content is sent to an AI provider?

Free local tools do not need an external AI provider. When you deliberately invoke an entitled Pro AI action, the content required for that action can be sent through Barnd AI SEO API to the configured provider. See the Privacy Policy and Security page for the boundary.

Does Barnd AI SEO guarantee rankings?

No. It helps identify issues, improve process and generate reviewable SEO work. Search engines and AI answer systems decide what they crawl, index, rank, cite or surface.

Can I use another SEO plugin at the same time?

Be careful with duplicate output. Only one plugin should normally own live metadata, schema and sitemap output for the same surface. Use Barnd AI SEO's review tools to understand existing SEO-plugin data before enabling overlapping output.

How does pricing work?

SEO Free is free. The current public plan presentation is C$89 one-time for SEO Pro on one site, with a C$149 Complete one-site bundle shown for SEO Pro + Shield Pro. Production checkout is not yet connected on this branch; final Paddle configuration will be verified before general sales open.

Is there an agency plan?

The product architecture supports site limits and agency groundwork, but general public agency checkout should only be advertised once its final commercial terms and billing mapping are activated.

What should I send support?

Send product/version details, the page or action involved, and a non-secret diagnostic summary. Never send passwords, private signing keys, database credentials, payment-card data or provider API keys by email.
