Security is part of the product

One customer should never become another customer.

Unique installation keys

Pro installations use individual Ed25519 signing identities. Copying a plugin or database does not silently create another authorized site.

Replay-resistant requests

Signed requests bind the installation, request path, body, timestamp, and nonce so tampered or replayed requests fail closed.

Provider-key isolation

The AI provider credential lives on the Barnd API server. WordPress receives a Barnd site identity, not our upstream provider secret.
