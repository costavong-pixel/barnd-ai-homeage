Support

Help with Barnd AI

For installation, activation, billing or product questions, start with the documentation and send only the details needed to reproduce the problem.

Support email: support@barndai.com
Commercial support routing should be verified before general public launch.

Before contacting support

  • Include the product name and exact Free/Pro version.
  • Include the WordPress and PHP versions.
  • Describe the page/action you used, what you expected and what happened.
  • Include a non-secret diagnostic/support export when available.
  • Do not email passwords, database credentials, private signing keys, API keys, payment-card details or raw authorization headers.

SEO Pro connection problems

Do not copy another site's cloud ID, site token, installation ID or Ed25519 key. A legitimate installation should use the normal activation or rebind workflow so the API can enforce tenant and site boundaries.

Controlled beta access

SEO Pro has passed final engineering/release inspection and is ready for controlled customers. Public checkout remains closed while Paddle product, webhook and entitlement E2E are configured. Existing controlled testers should use their assigned activation path rather than creating manual licence/database records.

Billing and refunds

When production checkout opens, keep the transaction/order reference from the payment receipt. Refund handling follows the published Refund Policy and the payment provider's transaction flow.

Security issue?

If you believe you found a security problem, do not post credentials or exploit details publicly. Contact support with the affected product/version and enough non-secret information for us to reproduce the issue safely.
