Customer guide

From install to a better SEO habit.

Follow the same calm loop each time: understand your site, choose what to do, verify the result, and keep the next scan visible.

1. Install Free

  1. Download the Free ZIP from the downloads page.
  2. In WordPress, open Plugins → Add New → Upload Plugin.
  3. Upload the ZIP, activate Barnd AI SEO, and open the plugin.

2. Add Pro when ready

After a paid purchase, use your Paddle transaction ID and purchase email on the secure downloads page. Install Pro after Free, then open Barnd AI SEO → SEO Pro and paste the private activation key.

3. Run the Setup Wizard

The Wizard configures the product rather than merely showing a checklist. Confirm your site identity, business type, local details, schema defaults, monitoring preferences, and review-first safety defaults.

4. Run your baseline audit

Barnd checks the pages and media that exist on your site. Findings explain the issue, the affected object, and the next useful action. Start with the highest-impact, lowest-risk items.

5. Configure automatic scans

Choose a scan cadence and which safe checks may run automatically. Keep content additions, FAQ changes, and other review-required work in the queue until you approve it.

6. Review AI recommendations

Pro can prepare titles, meta descriptions, image ALT, internal-link suggestions, and visible FAQ content. Each draft shows the source object, current value, proposed value, and why it was suggested.

7. Apply and verify

Apply requires the right WordPress capability, a nonce, a matching current value, and a validated proposal. Afterward, check the saved WordPress state and public HTML. If the source changed since generation, Barnd asks you to review again.

8. Roll back a specific change

Open the applied draft and choose Roll back. Barnd restores only the bounded value recorded for that change; it does not restore a whole database snapshot.

9. Reports and monitoring

The Dashboard shows current health, new findings, what Barnd fixed, what needs approval, the last scan, and what happens next. Reports keep the history readable without exposing unnecessary content.

10. Updates

Entitled Pro installations receive signed private updates. The updater checks the manifest signature, package hash, expiry, entitlement, and installation identity before installing.

11. Support

If something looks wrong, open Support and include the site URL, plugin versions, and the non-secret diagnostic code. Never send passwords, private keys, activation keys, or provider credentials.

What Barnd does not promise: rankings, indexing, traffic, or inclusion in AI-generated answers. It improves the work you control.
