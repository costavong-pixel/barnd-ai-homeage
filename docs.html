Barnd AI SEO setup and operating guide

Start local with SEO Free. Connect Pro only when you need server-assisted workflows.

1. Install SEO Free

  1. Download the approved Barnd AI SEO Free ZIP.
  2. Open WordPress → Plugins → Add New → Upload Plugin.
  3. Upload and activate Barnd AI SEO.
  4. Open Setup and select the website category that best matches the site.
  5. Run the SEO Audit and review the highest-value items first.
No account required: the included Free SEO tools work locally and do not require a Pro licence or provider API key.

2. Use the Free workflow

Use the local tools to inspect titles, descriptions, canonical/noindex settings, schema, sitemaps, image ALT coverage, local SEO, redirects, 404s, internal links and performance-import opportunities. AI Discoverability Snapshot is also available as a local review workflow.

3. Connect Pro

Pro activation establishes a server-authoritative entitlement and site binding. During the hardened onboarding flow, the installation receives its own Ed25519 signing identity. The private signing key remains on that WordPress installation; the API stores the public identity needed to verify requests.

SEO Free ↓ install Pro Pro activation / entitlement ↓ Unique installation identity ↓ signed requests Barnd AI SEO API

4. Run an AI-assisted SEO action

When an entitled Pro feature is invoked, the plugin signs the request. The Barnd API verifies the installation, timestamp, nonce, capability, tenant/resource ownership and applicable rate/cost controls before provider execution.

Current controlled-rollout provider routing uses DeepSeek Flash V4 on the server side. Customers do not configure or receive the upstream provider key.

5. Review before consequential changes

AI output is a draft or recommendation unless the installation has a separately authorized mutation/publishing capability. Customer defaults should remain review-first. Business facts, prices, hours, addresses and other factual claims should be verified before publication.

6. Pro updates

Pro can use a private update path that validates entitlement and package/manifest integrity. Do not install a Pro ZIP received from an untrusted source or an attachment whose integrity cannot be verified.

7. Disconnect, revoke or rotate

A site binding or signing key can be revoked without exposing the provider credential or affecting unrelated customers. Key rotation is designed to replace one installation identity while preserving tenant separation.

Troubleshooting

Pro says the site is not activated

Confirm Free is active and the local site identity exists, then run the normal Pro activation flow. Do not manually copy another site's cloud ID, token, installation ID or key material.

A signed request is rejected

Check system time, site URL/binding, entitlement state and whether the key was rotated or revoked. Replay, tamper, wrong-site and expired requests are intentionally rejected.

The AI provider is unavailable

Free/local tools should continue to work. Pro provider failures should fail closed rather than exposing credentials or silently switching to an unauthorized path.

I cloned the site

A copied WordPress database/plugin should not automatically become another authorized customer installation. Use the supported rebind/reactivation process instead of copying credentials.
